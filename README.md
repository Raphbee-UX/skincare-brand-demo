# Boss Beauty — storefront prototype

A responsive React + Vite storefront concept based on the visual references in this repository.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Prototype notes

- The visible product names are based on packaging identifiable in the reference screenshots.
- Prices are illustrative placeholders and must be confirmed by the brand owner.
- Product photography currently uses crops of the reference screenshots hosted in this repository. Replace these with clean, approved product photos before launch.
- The cart, search, filters and newsletter are client-side demonstrations only.
- Checkout does not process payments. Newsletter submissions are not transmitted or stored.
- Testimonials are explicitly marked as demonstration content.
- Contact and social destinations are placeholders.

This is a concept storefront, not a production commerce integration.
